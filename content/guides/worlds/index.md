# Multiple worlds

A TruWorlds game can be more than one world. A [project](universes-and-worlds.md) is one game as players see it: one page, one name, one Play button. A project holds one or more worlds. A lobby that sends groups into matches, a hub with doors to separate adventures, a tutorial that hands players on to the main game: each of these is one project holding several worlds, with scripts that move players from one to the next. You create and [configure projects](publishing-your-game.md) and worlds on the Create site.

## Teleporting

The [`TeleportSystem`](teleporting.md) sends players from a server of one world to a server of another, optionally with a [small table of data](teleport-data.md). A [reserved server](reserved-servers.md) is a private server of one of your worlds.
