# Playtesting

A [playtest](starting-a-playtest.md) runs a [copy](what-a-playtest-keeps.md) of your world inside TruWorlds Creator. It runs one server and one to four players. The server and each player run their own copy of that world; each one is called a session, and has its own tab.

## Spawning

[Spawning](player-start-and-spawning.md) is the server putting a player's character somewhere: when the player joins, and every time their character comes back after dying.

## Debugging

A playtest is the only place where you can watch the server and several players [side by side](switching-sessions.md) on one computer. Almost every [multiplayer bug](debugging-a-playtest.md) becomes easier once you know which side it is on. [Low frame rate](slow-worlds.md), hitches or a playtest that feels heavy are a different kind of bug.
